Alur

Bagaimana konsepnya bekerja

Ada dua peran utama. Pelanggan memesan menu, sedangkan admin mengelola menu dan pesanan yang masuk.

Pelanggan

  1. 1
    Lihat menu

    Pengunjung membaca daftar menu, deskripsi singkat, dan harga.

  2. 2
    Pilih menu

    Menu yang dipilih masuk ke keranjang dan bisa diubah jumlahnya.

  3. 3
    Isi data pesanan

    Nama, nomor telepon, alamat pengiriman, dan catatan tambahan.

  4. 4
    Checkout

    Pesanan dikonfirmasi lalu diteruskan ke admin untuk diproses.

Admin

  1. 1
    Kelola menu

    Menambah, mengubah, atau menonaktifkan menu yang tampil.

  2. 2
    Pantau pesanan

    Melihat pesanan masuk beserta detail pelanggan dan totalnya.

  3. 3
    Konfirmasi

    Menghubungi pelanggan dan menandai pesanan sebagai diproses.

Catatan: pada versi dummy ini, tahap pengisian data dan checkout disederhanakan menjadi satu tombol simulasi.

Poin untuk dijelaskan

  • Keranjang menyimpan pilihan pelanggan sebelum checkout.
  • Total dihitung otomatis dari harga menu dikali jumlah.
  • Checkout di sini hanya simulasi, tidak mengirim data ke server.
  • Isi keranjang disimpan di localStorage, jadi tetap ada saat halaman dimuat ulang.

Untuk demonstrasi: buka DevTools → Application → Local Storage.

Teknologi

Hanya HTML, CSS, dan JavaScript

Tidak ada PHP, MySQL, gambar, atau pustaka eksternal. Seluruh isi situs terdiri dari tiga file yang saling terhubung.

HTML

Menyusun struktur halaman: bagian konsep, alur, daftar menu, simulasi keranjang, dan penjelasan teknologi.

CSS

Mengatur tampilan, warna, jarak, dan tata letak responsif agar nyaman dibaca di laptop maupun ponsel.

JavaScript

Menangani data menu dummy, filter kategori, keranjang, perhitungan total, dan simulasi checkout.

Batasan versi dummy

  • Data menu dan pesanan tidak tersimpan permanen di server.
  • Tidak ada login, pembayaran, atau pengiriman pesanan sungguhan.
  • Fokus versi ini adalah konsep alur dan tampilan, bukan sistem produksi.
